# MCP 기준

**기본: MCP를 붙이지 않는다.** Codex는 셸, 파일, 내장 웹 검색으로 과제를 끝낼 수 있고, MCP는 설정·재시작 시간과 토큰을 쓰며 외부 호출을 늘린다.

| 후보 | 판단 | 이유 |
| --- | --- | --- |
| Context7 (라이브러리 문서) | 미채택 | 외부 서비스 호출이 생긴다. 문서 확인은 Codex 내장 웹 검색으로 대신한다 |
| Playwright (브라우저 조작) | 미채택 | 화면은 미리보기로 직접 확인하고, 기록용 점검은 `scripts/ui_check.py`로 한다. 페이지 구조를 통째로 대화에 넣어 토큰이 크고 메모리 부담이 있다 |
| GitHub | 미채택 | push 금지 |
| Filesystem·Git | 미채택 | 셸과 중복 |
| Sequential-thinking류 | 미채택 | 토큰만 늘어남 |

`DECISIONS.md`에 한 줄: `MCP 미사용: 셸·웹 검색으로 충분, 외부 호출·설정 시간·토큰 절약`.

## 그래도 필요해지면

이 키트에서는 MCP를 도입하지 않는다. 필요한 기능은 skill·패키지로 `prompts/codex.md`의 K13 절차를 따르고, 규정상 허용되는지 불확실하면 Cofa Helper에 먼저 묻는다.
