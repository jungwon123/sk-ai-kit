# INTERVIEW — 업무 담당자 대화 기록

처음에는 해결책(자동화·AI) 이야기를 꺼내지 않고 업무와 숫자부터 묻는다.
순서: 사례 → 지금 방식(워크어라운드) → 숫자(시간·빈도·비용) → 누가 쓰나 → 범위(만들 것/안 만들 것)

## 질문과 답

| 시각 | 질문 | 답 | 반영 위치 |
| --- | --- | --- | --- |
|  | 최근에 이 일로 가장 힘들었던 사례는? |  |  |
|  | 지금은 어떻게 처리하고, 한 번에 얼마나 걸리나? 얼마나 자주? |  |  |
|  | 이 도구는 누가 언제 쓰나? |  |  |
|  | 잘 됐다고 판단하려면 어떤 숫자가 어떻게 바뀌어야 하나? |  |  |
|  | 우선순위가 가장 높은 것과 이번에 만들지 않아도 되는 것은? |  |  |
