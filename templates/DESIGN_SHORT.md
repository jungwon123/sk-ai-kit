# DESIGN_SHORT (구현용 요약, 40줄 이내)

T1이 구현할 때 읽는 파일이다. 자세한 설계(`DESIGN.md`)는 T1이 읽지 않는다(컨텍스트 절약).
`DESIGN.md`를 고친 쪽(K3, K3-1, K8-1, K14)이 이 파일도 같이 갱신한다. 표·설명 없이 한 줄씩만 쓴다.

## 흐름
- 입력 → 적재(`파일:함수`) → 검증 → 저장(어디) → 계산(`파일:함수`) → API(경로) → 화면

## 핵심 함수 (구현 시 이 이름을 지킨다)
- `파일:함수` — 하는 일 한 줄

## 기준값 (코드 위치)
- 이름 = 값 (근거: 담당자 HH:MM / 내 가정), 경계: 이상·초과, 위치 `파일:줄`

## 예외 처리 방식
- 케이스 → 처리 방식(거부·제외+경고·보정·분리·최선의 답), 위치

## 지킬 것
- 필수 규칙·금지 사항 (README·합의문에서)

## 미정
- 아직 정하지 않은 것 (정할 사람: 나 / 담당자)
