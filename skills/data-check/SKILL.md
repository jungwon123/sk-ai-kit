# skill: data-check — 데이터 점검과 정제 규칙 정리

## 절차
1. `python3 scripts/profile_data.py data --out out/profile.md` 를 실행한다. (경로는 과제에 맞게. pandas가 없으면 `pip install pandas openpyxl`)
2. 결과에서 다음을 찾는다:
   - 파일별 행 수, 결측, 완전 중복 행
   - **표기 변형**: 대소문자·공백·하이픈만 다른 ID (예: `ETC-07` / `etc07`)
   - **단위 컬럼**: 이름에 unit/단위가 있거나 같은 측정값의 자릿수가 크게 다른 경우
   - 0·음수·빈 값처럼 '측정 실패'일 수 있는 값
   - 날짜 범위, 같은 키가 여러 번 나오는 경우(재작업·이력 중복)
   - 파일 간 조인 키와 조인 시 행 수 변화
3. `DATA_NOTES.md`를 채운다: 파일 요약, 정제 규칙 후보(근거: 관찰), 담당자 확인 필요 항목.
4. **규칙을 확정하지 않은 것은 '확인 필요'로 남기고 추측으로 처리하지 않는다.**
5. 데이터 원본을 대화에 통째로 출력하지 않는다. 요약만 보고한다.
