# skill: edge-cases — 예외·엣지 케이스 찾기와 처리

예외 처리는 설계 설명에서 거의 반드시 묻는다. 아래 목록을 **과제 데이터와 README에 대어 보고**, 해당하는 것만 표로 만든다. 괄호 안 예시(배송·예약·설비 일정 등)는 이해를 돕기 위한 것이고, 과제마다 바꿔 읽는다.

## 1. 찾는 순서

1. README·합의문·DATA_NOTES에서 **시간, 상태, 분류, 경계값**이 들어간 단어를 모두 뽑는다(근무조, 휴무, 마감, 이상·초과, 정원 등).
2. 아래 체크리스트를 한 줄씩 대어 보고 "해당 / 해당 없음(이유)"을 정한다.
3. 해당하는 것마다 **사실은 담당자에게 묻고(D1-2), 처리 방식은 내가 정해 제안한다(D2-1 방식).** 묻는 건 사실("야간 근무자도 대상인가요?")이고, 정하는 건 방식("대상이면 별도 그룹으로 묶겠습니다")이다.
4. 결과를 DESIGN.md §8 예외 표와 DECISIONS '서술형 재료 4'에 적는다. 케이스마다 테스트 하나(`test_<케이스>`)를 붙인다.

## 2. 체크리스트

### 시간·일정
- [ ] 휴무·결근·휴가·공휴일: 그날 대상에서 빠지나, 빠진 사람 때문에 결과가 바뀌나 (휴무자 제외 후 배정 재계산 / 용량 재계산)
- [ ] 근무조·야간·교대: 주간과 섞어 처리하나 분리하나 (야간 건을 별도 일정으로 만드나)
- [ ] 자정 넘김: 22:00~06:00 근무의 날짜는 시작일인가 종료일인가, `end < start` 비교 버그
- [ ] 시간대·형식: UTC `Z`, 시간대 없는 시각, `24:00`, 초 유무
- [ ] 경계 시각: 정확히 마감 시각인 건 포함인가 (이상/초과), 반올림 전·후 어느 쪽으로 비교하나
- [ ] 기간 밖·미래 날짜·순서 뒤집힘(시작 > 종료)

### 데이터 품질
- [ ] 결측: 필수 열이 비었을 때 거부 / 기본값 / 제외 후 경고
- [ ] 중복: 같은 키가 두 번 (최신 우선? 오류?)
- [ ] 참조 깨짐: 다른 표에 없는 ID를 가리킴 (없는 지점·없는 설비)
- [ ] 형식 오류: 숫자 칸에 글자, 날짜 형식 섞임, 인코딩(CP949), 열 이름 공백
- [ ] 이상치·불가능한 값: 음수, 0, 좌표 범위 밖, 물리적으로 불가능한 시간
- [ ] 단위 혼동: 분/초, m/km, %/비율

### 규모·극단
- [ ] 0건, 1건 (빈 결과 화면 문구, 0으로 나누기)
- [ ] 모두 같은 값 / 한 그룹에 몰림
- [ ] 정원·용량 초과 (한 자원에 다 안 들어감 → 나누기? 추가 배정? 경고?)
- [ ] 대량 (현재의 10배·100배: 시간·메모리, 화면 페이지 나눔)

### 해 없음·충돌
- [ ] 제약을 모두 만족하는 답이 없을 때 (거리·시간 기준 안에 후보가 없음): 실패로 멈추나, 가장 덜 어긋난 답 + 위반 목록을 보여주나
- [ ] 규칙끼리 충돌 (시간 최소 vs 대수 최소): 무엇이 강제 규칙이고 무엇이 평가 지표인가
- [ ] 동점: 같은 점수일 때 순서를 어떻게 고정하나 (결과가 실행마다 달라지지 않게)

### 상태·운영
- [ ] 데이터 교체 중 실패: 기존 데이터 유지
- [ ] 데이터·조건이 바뀌었는데 결과는 옛날 것: 화면에 상태 표시, 내보내기 막기
- [ ] 동시 실행·중복 클릭, 재시작 후 상태
- [ ] 권한: 구성원이 운영자 기능 호출, 다른 사람 결과 조회

## 3. 처리 방식 고르기

| 방식 | 언제 | 예 |
| --- | --- | --- |
| 거부 (사람이 읽는 오류: 파일·행·열) | 결과가 틀릴 수밖에 없는 입력 | 참조 깨짐, 필수 열 없음 |
| 제외 + 경고 표시 | 일부만 문제이고 나머지는 의미가 있음 | 좌표 없는 1명 제외, 화면에 "1명 제외(사유)" |
| 보정 (규칙 명시) | 담당자가 보정 규칙을 확인해 줬을 때만 | 공백 제거, 형식 통일 |
| 분리 처리 | 성격이 다른 집단 | 야간 건을 별도 일정으로 |
| 최선의 답 + 위반 목록 | 해가 없거나 제약이 충돌 | 기준 초과 인원 수와 명단 |

원칙: **조용히 고치지 않는다.** 바꾸거나 뺀 것은 화면·내보내기·로그 중 한 곳에 반드시 보인다. 담당자 확인 없이 정한 처리는 DECISIONS에 "내 가정"으로 적는다.
