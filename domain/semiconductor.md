# 반도체 공정 데이터 기초 (공개 일반 지식 요약)

과제 데이터가 반도체 공정·설비·수율 관련일 때 용어를 해석하고 분석 방향을 잡기 위한 참고 자료다.
실제 값의 의미와 기준(한계값, 제외 규칙)은 **반드시 과제 안내와 업무 담당자 확인**을 따른다.

## 용어

| 용어 | 뜻 | 데이터에서 보이는 형태 |
| --- | --- | --- |
| Lot / Wafer / Die(Chip) | 생산 단위. Lot 1개 = 웨이퍼 약 25장, 웨이퍼 1장 = 칩 수백~수천 개 | lot_id, wafer_id, die_x/die_y |
| 수율(Yield) | 양품 수 ÷ 전체 수. 웨이퍼·Lot·제품 단위로 집계 | good_die, total_die, yield |
| Bin | 테스트 결과 분류 코드(양품/불량 유형) | bin, bin_code |
| 공정 단계(Step) / 레시피(Recipe) | 웨이퍼가 거치는 단계와 각 단계 설정 | step, recipe_id, route |
| 설비(EQP) / 챔버(Chamber) | 같은 설비라도 챔버별 상태가 다를 수 있음 | eqp_id, chamber, tool_id |
| 재작업(Rework) | 같은 단계를 다시 수행. 이력 중복의 흔한 원인 | rework flag, 같은 lot·step 중복 행 |
| SPC | 통계적 공정 관리. 관리한계(보통 평균 ± 3σ) 이탈을 감시 | OOC(관리한계 이탈), OOS(규격 이탈) |
| FDC | 공정 중 센서 데이터(압력, 온도, RF 파워, 가스 유량) 감시 | 센서 요약값, 시계열 |
| PM | 예방 정비. 정비 직후 조건 변화가 생길 수 있음 | pm_date, pm_type, 정비 내용 |
| 웨이퍼 맵 | 웨이퍼 위 불량 위치 패턴(가장자리, 중앙, 스크래치 등) | 좌표별 pass/fail |
| CD / 두께 / 결함 수 | 계측값. 규격(spec)과 비교 | measurement, spec_low/high |

## 자주 쓰는 분석 패턴

1. **공통성 분석(Commonality)**: 저수율 Lot들이 공통으로 거친 설비·챔버·시간대를 찾는다. 설비·챔버별 저수율 Lot 비율과 Lot 수를 함께 본다(표본이 적은 그룹 주의).
2. **혼재 요인 보정**: 제품·레시피 구성이 설비마다 다르면 원값 비교가 왜곡된다. 제품별 기준 대비 편차로 비교한다.
3. **전후 비교**: PM·레시피 변경 시점 전후의 수율·센서값을 비교한다. 시점 당일 포함 여부를 명시한다.
4. **SPC 이탈 탐지**: 기준 기간으로 평균·표준편차를 구해 관리한계를 정한다. 기준 기간·그룹 단위(설비별 vs 공통)는 표본 수를 보고 정하고, 담당자와 합의한다. 단발 이탈과 연속·누적 이탈을 구분한다.
5. **텍스트 분류**: 정비 로그·불량 메모는 키워드 사전·정규식 규칙(필요하면 로컬 TF-IDF 등, `kit/refs/REPOS.md`)으로 분류한다. 라벨이 있는 일부로 정확도를 측정하고 결과는 정해진 형식으로 남긴다. 외부 LLM은 호출하지 않는다.

## 데이터 정제에서 흔한 함정

- 같은 설비의 다른 표기(대소문자, 하이픈, 공백, 접두어 `CH-`)
- 단위 혼재(Torr / mTorr, % / ppm, ℃ / K) — 단위 컬럼이나 로거·시스템 구분 컬럼 확인
- 0 또는 공란이 '측정 실패'를 뜻하는 경우 → 0으로 계산하지 말고 제외 규칙을 확인
- 재작업·재측정으로 같은 키가 여러 번 → 어떤 이력을 쓸지(최종/최초) 확인
- 조인 후 행 수 증가(1:N 관계) → 조인 전후 행 수를 반드시 확인
