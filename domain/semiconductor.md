# 반도체 공정 데이터 기초 (공개 일반 지식 요약)

과제 데이터가 반도체 공정·설비·수율 관련일 때 용어를 해석하고 분석 방향을 잡기 위한 참고 자료다.
실제 값의 의미와 기준(한계값, 제외 규칙)은 **반드시 과제 안내와 업무 담당자 확인**을 따른다.

## 용어

| 용어 | 뜻 | 데이터에서 보이는 형태 |
| --- | --- | --- |
| Lot / Wafer / Die(Chip) | 생산 단위. Lot 1개 = 웨이퍼 약 25장, 웨이퍼 1장 = 칩 수백~수천 개 | lot_id, wafer_id, die_x/die_y |
| 수율(Yield) | 양품 수 ÷ 전체 수. 웨이퍼·Lot·제품 단위로 집계 | good_die, total_die, yield |
| Bin | 테스트 결과 분류 코드(양품/불량 유형) | bin, bin_code |
| 공정 단계(Step) / 레시피(Recipe) | 웨이퍼가 거치는 단계와 각 단계 설정 | step, recipe_id, route |
| 설비(EQP) / 챔버(Chamber) | 같은 설비라도 챔버별 상태가 다를 수 있음 | eqp_id, chamber, tool_id |
| 재작업(Rework) | 같은 단계를 다시 수행. 이력 중복의 흔한 원인 | rework flag, 같은 lot·step 중복 행 |
| SPC | 통계적 공정 관리. 관리한계(보통 평균 ± 3σ) 이탈을 감시 | OOC(관리한계 이탈), OOS(규격 이탈) |
| FDC | 공정 중 센서 데이터(압력, 온도, RF 파워, 가스 유량) 감시 | 센서 요약값, 시계열 |
| PM | 예방 정비. 정비 직후 조건 변화가 생길 수 있음 | pm_date, pm_type, 정비 내용 |
| 웨이퍼 맵 | 웨이퍼 위 불량 위치 패턴(가장자리, 중앙, 스크래치 등) | 좌표별 pass/fail |
| CD / 두께 / 결함 수 | 계측값. 규격(spec)과 비교 | measurement, spec_low/high |

| 샷(Shot) / 레티클(Reticle) | 노광 한 번에 찍히는 영역. 한 샷에 칩 여러 개가 들어감 | shot_x/shot_y, 샷 안 칩 위치. 샷마다 같은 위치에 반복되는 불량 = 레티클(마스크) 문제 의심 |
| 큐타임(Q-time) | 두 공정 사이 허용 대기 시간. 넘기면 산화·오염으로 불량 가능 | 단계별 진입·완료 시각의 차이 |
| Lot 분할·병합(Split/Merge) | 실험·재작업으로 lot을 나누거나 합침. 이력 추적이 끊기는 흔한 원인 | parent_lot, child_lot, split 플래그 |
| Hold / 엔지니어링 lot | 이상으로 멈춘 lot, 실험용 lot. 분석에서 따로 다루거나 제외 | hold 사유, lot 유형 |
| 인라인 결함 검사·리뷰 | 공정 중간 웨이퍼 표면 결함 검출(검사) → 일부를 확대 촬영해 분류(리뷰, ADC) | 결함 좌표·크기·분류 코드, 킬러 결함 비율 |
| 가상 계측(VM) | 계측하지 않은 웨이퍼의 계측값을 센서 데이터로 예측 | FDC 요약 → CD·두께 예측값 |
| APC / R2R | 직전 계측 결과로 다음 웨이퍼·lot의 레시피를 자동 보정 | 보정량 로그. 보정 때문에 원인이 가려질 수 있음 |
| 하드 빈 / 소프트 빈 | 큰 분류(양품·불량 범주)와 세부 불량 원인 코드 | hard_bin, soft_bin |
| PCM / ET | 칩 사이 스크라이브 라인의 테스트 패턴 전기 특성 | 웨이퍼별 수십 점 측정값 |

## 메모리 제품과 테스트 흐름

- **흐름**: 웨이퍼 테스트(EDS, 프로브) → 리페어(여분 셀 교체) → 재테스트 → 패키지 → 패키지 테스트(번인 포함) → 모듈 테스트. 단계마다 수율이 따로 있다.
- **리페어 전·후 수율**: 공정 결함은 리페어 전, 출하 가능 수량은 리페어 후. 분석 전에 어느 쪽인지 확인한다.
- **번인(Burn-in)**: 고온·고전압으로 초기 불량을 미리 걸러 내는 테스트. 초기 고장률이 시간에 따라 줄어드는 구간(욕조 곡선의 앞부분)을 제거한다.
- **HBM**: DRAM 칩 여러 장을 TSV(실리콘 관통 전극)로 수직 적층하고 아래에 베이스(로직) 다이를 둔 고대역폭 메모리. 한 장이라도 불량이면 스택 전체가 손실되므로, 적층 전에 양품이 확인된 다이(KGD)를 골라 쓰는 것이 중요하다.
- **적층 수율**: 스택 수율 ≈ (각 다이 수율의 곱) × (접합·적층 공정 수율). 다이 수율 98%라도 12단이면 0.98¹² ≈ 78%. 다이 수율의 작은 차이가 스택에서 크게 벌어진다.
- **테스트 시간·비용**: 테스트 항목을 줄이면 비용이 줄지만 불량 유출(escape) 위험이 커진다. "어떤 테스트를 빼도 되나"는 현업의 단골 질문이다.

## 설비 운영 지표 (배정·스케줄링·정비 과제)

| 지표 | 뜻 | 메모 |
| --- | --- | --- |
| 설비 상태 | 생산·대기·정비(계획/비계획)·엔지니어링 등으로 시간 구분 (SEMI E10 계열) | 가동률 계산의 기준 |
| OEE | 가용률 × 성능률 × 품질률 | 어디서 손실이 나는지 분해 |
| MTBF / MTTR | 평균 고장 간격 / 평균 수리 시간 | 예지 정비 효과 측정 |
| 사이클 타임 / WIP / 처리량 | 리틀의 법칙: WIP = 처리량 × 사이클 타임 | 병목 설비 앞에 WIP가 쌓인다 |
| 디스패칭 규칙 | 다음에 처리할 lot을 고르는 규칙: FIFO, 납기 우선(EDD), 임계 비율(CR), 큐타임 임박 우선 | 최적화 과제의 기준선으로 쓰기 좋다 |
| 셋업·레시피 전환 | 같은 레시피를 묶으면 전환 시간이 준다 | 배정 문제의 대표 트레이드오프 |

## 자주 쓰는 분석 패턴

1. **공통성 분석(Commonality)**: 저수율 Lot들이 공통으로 거친 설비·챔버·시간대를 찾는다. 설비·챔버별 저수율 Lot 비율과 Lot 수를 함께 본다(표본이 적은 그룹 주의).
2. **혼재 요인 보정**: 제품·레시피 구성이 설비마다 다르면 원값 비교가 왜곡된다. 제품별 기준 대비 편차로 비교한다.
3. **전후 비교**: PM·레시피 변경 시점 전후의 수율·센서값을 비교한다. 시점 당일 포함 여부를 명시한다.
4. **SPC 이탈 탐지**: 기준 기간으로 평균·표준편차를 구해 관리한계를 정한다. 기준 기간·그룹 단위(설비별 vs 공통)는 표본 수를 보고 정하고, 담당자와 합의한다. 단발 이탈과 연속·누적 이탈을 구분한다.
5. **큐타임·대기 분석**: 단계 사이 대기 시간이 길었던 웨이퍼의 수율을 비교한다. 대기 시간 구간별 불량률 곡선으로 허용 한계를 확인한다.
6. **샷·레티클 패턴**: 샷 안 칩 위치별 불량률을 모든 샷에 걸쳐 합산한다. 특정 위치만 높으면 레티클 결함을 의심한다.
7. **텍스트 분류**: 정비 로그·불량 메모는 키워드 사전·정규식 규칙(필요하면 로컬 TF-IDF 등, `kit/refs/REPOS.md`)으로 분류한다. 라벨이 있는 일부로 정확도를 측정하고 결과는 정해진 형식으로 남긴다. 외부 LLM은 호출하지 않는다.

## 데이터 정제에서 흔한 함정

- 같은 설비의 다른 표기(대소문자, 하이픈, 공백, 접두어 `CH-`)
- 단위 혼재(Torr / mTorr, % / ppm, ℃ / K) — 단위 컬럼이나 로거·시스템 구분 컬럼 확인
- 0 또는 공란이 '측정 실패'를 뜻하는 경우 → 0으로 계산하지 말고 제외 규칙을 확인
- 재작업·재측정으로 같은 키가 여러 번 → 어떤 이력을 쓸지(최종/최초) 확인
- 조인 후 행 수 증가(1:N 관계) → 조인 전후 행 수를 반드시 확인
- 시각 기준 혼동: 테스트 시각인가 해당 공정 진행 시각인가. "언제부터 나빠졌나"는 공정 시각 기준으로 본다
- lot 분할·병합으로 이력이 끊김 → parent/child 관계로 이어 붙인다
- 엔지니어링 lot·hold lot이 섞여 평균을 왜곡 → 유형별로 나누거나 제외 규칙을 확인
