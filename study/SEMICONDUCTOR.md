# 반도체 개념 정리 (사람용, Codex는 읽지 않는다)

데이터를 보고 담당자와 대화하고 결과를 설명하는 데 필요한 만큼의 반도체 지식이다. 소자 물리는 다루지 않는다.
공개된 일반 지식이며, 수율 정의·bin 체계·공정 이름은 회사마다 다르니 현장에서 담당자에게 확인한다. 아래 숫자 예시는 모두 계산 연습용이다.

## 1. 큰 그림: 웨이퍼 한 장이 칩이 되기까지

```
웨이퍼 제조 → [전공정 FAB: 산화 → 포토 → 식각 → 증착 → 이온주입 → 금속배선, 수백 단계 반복]
           → EDS(웨이퍼 테스트) → 리페어 → 패키징 → 패키지 테스트(번인 포함) → 모듈 → 출하
```

| 단계 | 하는 일 | 남는 데이터 | 흔한 문제 |
| --- | --- | --- | --- |
| 산화 | 실리콘 표면에 산화막(절연막)을 키움 | 막 두께 계측 | 두께 불균일 |
| 포토(노광) | 감광액을 바르고 마스크(레티클) 패턴을 빛으로 새김. 공정 중 가장 비싸고 병목이 잦음 | CD(선폭), 오버레이(층 간 정렬) | 초점·노광량 이탈, 레티클 결함(샷마다 같은 위치 반복 불량) |
| 식각 | 패턴대로 막을 깎음 (건식: 플라즈마) | FDC 센서(RF 파워, 압력, 가스), 식각 후 CD | 가장자리·중앙 불균일, 과·미식각 |
| 증착 | 얇은 막을 쌓음 (CVD, PVD, ALD) | 두께, 균일도 | 파티클, 두께 편차 |
| 이온주입 | 불순물을 넣어 전기적 성질을 만듦 | 주입량·에너지 | 전기 특성(PCM) 이탈 |
| CMP | 표면을 평평하게 연마 | 두께, 결함 | 스크래치(웨이퍼 맵에 선 모양) |
| 세정 | 공정 사이 오염 제거 | | 파티클 |
| 금속배선 | 회로를 잇는 금속선 형성 | 저항, 결함 | 단선·단락 |

- **큐타임(Q-time)**: 어떤 공정 사이에는 대기 허용 시간이 있다. 넘기면 표면 산화·오염으로 불량이 날 수 있어 "대기 시간 vs 불량률"이 분석 주제가 된다.
- **lot 흐름**: lot(보통 웨이퍼 25장)이 FOUP라는 상자에 담겨 단계를 이동한다. 실험이나 재작업으로 lot을 나누거나(split) 합치기도(merge) 해서 이력이 끊기는 일이 잦다.
- **같은 장비라도 챔버가 여럿**: 한 장비에 공정 챔버가 여러 개 있고, 챔버마다 상태가 다르다. 원인 분석은 보통 "장비 + 챔버" 단위로 한다.

## 2. 메모리 제품 기초

### DRAM
- 셀 하나 = 트랜지스터 1개 + 커패시터 1개(1T1C). 커패시터의 전하로 0/1을 저장한다.
- 전하가 조금씩 새므로 주기적으로 다시 써 줘야 한다(리프레시, 표준적으로 수십 ms 주기). 리프레시 전에 데이터가 사라지면 **리텐션 불량**. 고온에서 더 잘 생겨서 고온 테스트로 거른다.
- 행(row)·열(column) 격자 구조라 불량도 셀 하나, 한 줄 전체(행·열 불량) 같은 형태로 나타난다 → 여분 행·열로 리페어.

### NAND 플래시
- 전원이 꺼져도 데이터가 남는 저장 메모리. 셀 하나에 비트 1~4개(SLC·MLC·TLC·QLC). 비트가 많을수록 싸지만 느리고 수명이 짧다.
- 쓰고 지우기(P/E)를 반복하면 셀이 닳는다(내구성). 출하 시에도 일부 불량 블록을 허용하고 컨트롤러가 관리하며, 오류 정정(ECC)으로 비트 오류를 고친다.

### HBM (고대역폭 메모리)
- DRAM 칩(코어 다이) 여러 장을 수직으로 쌓고, TSV(실리콘 관통 전극)로 위아래를 연결한 뒤 맨 아래 베이스(로직) 다이 위에 올린다. AI 가속기 옆에 붙어 넓은 대역폭을 낸다.
- 적층 방식으로는 칩 사이를 채우는 재료와 접합 방법에 따라 여러 방식이 있다(예: MR-MUF, TC-NCF).
- **수율이 곱으로 깎인다**: 한 장이라도 불량이면 스택 전체가 손실 → 적층 전에 양품이 확인된 다이(KGD)를 고르는 테스트가 중요하다.

| 다이 수율 | 8단 | 12단 | 16단 |
| --- | --- | --- | --- |
| 98% | 0.98⁸ ≈ 85.1% | 0.98¹² ≈ 78.5% | 0.98¹⁶ ≈ 72.4% |
| 99% | | 0.99¹² ≈ 88.6% | |

다이 수율 1%p 차이(98 → 99%)가 12단에서는 약 10%p 차이가 된다(접합 수율은 따로 곱한다).

## 3. 테스트 흐름과 bin

| 단계 | 내용 | 데이터 |
| --- | --- | --- |
| EDS / 웨이퍼 테스트 | 프로브 카드의 바늘을 칩 패드에 대고 전기 테스트. 칩마다 bin 기록 | 칩 좌표(x, y), bin, 측정값 |
| 리페어 | 불량 셀 위치를 분석해 여분 행·열로 교체(레이저 퓨즈 등) | 리페어 전·후 결과 |
| 패키지 테스트 | 패키징 후 다시 기능·속도 테스트 | 패키지 단위 결과 |
| 번인 | 고온·고전압으로 오래 가동해 초기 불량을 미리 걸러 냄 | 번인 전·후 불량 |
| 스피드 빈닝 | 동작 속도 등급별로 분류 | 속도 등급 |

- **bin**: 테스트 결과 분류 번호. 보통 "Bin 1 = 양품"이고 나머지는 불량 유형이다(회사마다 다름).
- **하드 빈 / 소프트 빈**: 하드 빈은 큰 범주(양품, 기능 불량, 전기 특성 불량 등), 소프트 빈은 세부 원인 코드다.
- **테스트 데이터 형식**: 장비에 따라 STDF 같은 표준 형식으로 나오며, 분석할 때는 칩 단위 표(lot, wafer, x, y, bin, 측정값)로 펼친다.
- **테스트 비용 트레이드오프**: 항목을 줄이면 시간·비용이 줄지만 불량 유출(escape)이 늘어난다.

## 4. 웨이퍼와 칩 수

- 요즘 메모리는 대부분 지름 300mm 웨이퍼를 쓴다.
- 웨이퍼당 칩 수(대략) ≈ π(d/2)²/S − πd/√(2S) (d = 웨이퍼 지름, S = 칩 면적).
  예: d = 300mm, S = 100mm²이면 약 707 − 67 ≈ **640개**. 뒤의 항은 가장자리에서 잘려 나가는 칩이다.
- **가장자리 제외(edge exclusion)**: 웨이퍼 가장자리 몇 mm는 품질이 나빠 칩을 만들지 않거나 따로 본다. 가장자리 칩의 불량률이 원래 높다는 점은 설계 비교에서 위치 구성을 맞춰야 하는 이유다.
- **샷(shot)**: 노광 한 번에 찍히는 영역으로 칩 여러 개가 들어 있다. 모든 샷에서 같은 위치의 칩만 불량이면 레티클(마스크)을 의심한다.

## 5. 결함과 불량의 종류

| 구분 | 뜻 | 데이터에서 보이는 모습 |
| --- | --- | --- |
| 랜덤 결함 | 파티클 등 우연히 떨어지는 결함 | 웨이퍼 맵에 흩어진 점 |
| 시스템적 결함 | 설계·공정 조합에서 반복되는 결함(특정 패턴, 특정 위치) | 같은 위치·패턴 반복, 샷 반복 |
| 파라메트릭 불량 | 결함은 없지만 전기 특성이 규격을 벗어남 | 측정값 분포 이동, 가장자리·중앙 경사 |
| 킬러 결함 | 실제로 칩을 망가뜨리는 결함. 모든 결함이 킬러는 아님 | 결함이 떨어진 칩의 불량률 / 안 떨어진 칩의 불량률 |
| 엑스커션 | 갑자기 생긴 비정상 수율 하락 | 시간 추이의 급락, 특정 장비·기간에 몰림 |

**웨이퍼 맵 패턴과 흔한 가설** (가설일 뿐, 현장 확인 필요)

| 패턴 | 모습 | 흔히 의심하는 것 |
| --- | --- | --- |
| Edge-ring | 가장자리 고리 | 가장자리 균일도(식각·증착·세정) |
| Center | 중앙 원 | 회전·분사 계열 공정 |
| Scratch | 선 모양 | 웨이퍼 취급, CMP |
| Loc / Cluster | 한 곳에 뭉침 | 국부 파티클, 장비 접촉 |
| Donut | 고리 모양(중앙 제외) | 온도·가스 분포 |
| Random | 고르게 흩어짐 | 일반 파티클 수준 |

## 6. 수율 정의와 모델

- **수율 층**: 라인 수율(웨이퍼가 라인을 통과한 비율) × 다이 수율(웨이퍼 안 양품 칩 비율) × 패키지·최종 수율. 메모리는 여기에 리페어 전·후가 더해진다.
- **결함 밀도 D₀**: 단위 면적(보통 cm²)당 치명 결함 수. 칩 면적 A가 클수록 결함을 맞을 확률이 커진다.

| 모델 | 식 | A·D₀ = 0.1 | A·D₀ = 0.5 | A·D₀ = 1.0 |
| --- | --- | --- | --- | --- |
| 포아송 (결함이 고르게) | Y = e^(−A·D₀) | 90.5% | 60.7% | 36.8% |
| 음이항 α = 2 (결함이 몰림) | Y = (1 + A·D₀/α)^(−α) | 90.7% | 64.0% | 44.4% |
| 머피 | Y = ((1 − e^(−A·D₀))/(A·D₀))² | | 61.9% | |

- 결함이 몰릴수록(α가 작을수록) 같은 결함 밀도에서도 수율이 높게 나온다. 몰린 결함이 한 칩에 겹치기 때문이다.
- **면적 정규화 예**: 기존 설계 A = 0.5cm², 수율 90% → D₀ = −ln(0.9)/0.5 ≈ 0.21. 신설계 A = 0.6cm², 수율 85% → D₀ ≈ 0.27. 수율만 보면 5%p 하락이지만, 면적 차이를 빼도 결함 밀도 자체가 높아졌다는 뜻이다(포아송 가정).

## 7. 공정 관리 데이터

| 이름 | 무엇 | 분석에서 |
| --- | --- | --- |
| SPC | 계측값·불량률을 관리도로 감시. 관리한계(보통 ±3σ) | 이탈 규칙, Cpk |
| FDC | 장비 센서(압력, 온도, RF 파워, 가스 유량)의 공정 중 시계열 | 단계별 요약 → 이상 감지 |
| APC / R2R | 직전 계측 결과로 다음 lot의 레시피를 자동 보정 | 보정이 원인을 가릴 수 있음 |
| VM (가상 계측) | 계측 안 한 웨이퍼의 계측값을 센서로 예측 | 회귀 모델, lot 단위 검증 |
| PCM / ET | 칩 사이 스크라이브 라인 테스트 패턴의 전기 특성 | 웨이퍼별 수십 점, 파라메트릭 분석 |
| 인라인 검사·리뷰 | 공정 중간 표면 결함 검출 → 일부를 확대 촬영해 분류(ADC) | 결함 좌표를 칩에 매핑, 킬러 비율 |
| PM | 예방 정비 기록 | PM 전후 수율·센서 변화 |

**Cp, Cpk**: Cp = (USL − LSL)/6σ(산포만), Cpk = min(USL − μ, μ − LSL)/3σ(치우침까지). 1.33 이상을 흔히 양호로 본다. 공정이 관리 상태일 때만 의미가 있다.

## 8. 팹 운영 지표 (배정·스케줄링 문제)

- **사이클 타임**: lot이 투입부터 완료까지 걸린 시간. **WIP**: 공정 중인 lot 수. **처리량**: 단위 시간당 완료 수.
- **리틀의 법칙**: WIP = 처리량 × 사이클 타임. 병목 장비 앞에 WIP가 쌓이고, 가동률이 100%에 가까워질수록 대기가 급격히 늘어난다.
- **장비 상태**: 생산·대기·계획 정비·고장·엔지니어링 등으로 시간을 나눠 가동률을 계산한다. OEE = 가용률 × 성능률 × 품질률.
- **MTBF / MTTR**: 평균 고장 간격 / 평균 수리 시간.
- **디스패칭 규칙**: 다음 처리할 lot을 고르는 규칙. FIFO(먼저 온 것), EDD(납기 빠른 것), CR(남은 시간 ÷ 남은 공정 시간이 작은 것), 큐타임 임박 우선.
- **제약**: 레시피별 가능 장비(자격), 레시피 전환 셋업 시간, 여러 lot을 한 번에 처리하는 배치 장비(퍼니스 등)의 배치 크기.

## 9. 손으로 해 보는 계산

**① 설계 효과(DEFF)**: 웨이퍼당 칩 m = 500, 같은 웨이퍼 칩끼리의 유사성(ICC) ρ = 0.02이면
DEFF = 1 + (m − 1)·ρ = 1 + 499 × 0.02 ≈ 11. 칩 12,000개를 비교해도 실제 정보량은 칩 약 1,100개 수준이다. 칩 단위 p값이 과장되는 이유다.

**② 웨이퍼 단위 비교**: 기존 웨이퍼 24장 평균 수율 80.0%(표준편차 3.0%p), 신설계 26장 78.8%(2.8%p).
차이(신 − 기존) = −1.2%p, 표준오차 = √(3.0²/24 + 2.8²/26) ≈ 0.82%p, 95% CI ≈ −1.2 ± 1.96 × 0.82 = **−2.8 ~ +0.4%p**.
- 0을 포함 → "이 표본으로는 신설계가 나빠졌다고 확정할 수 없다".
- 허용 한계 −1%p의 비열등성 기준이면 하한 −2.8이 −1보다 낮다 → "나쁘지 않다"고도 말할 수 없다.
- 결론: 판단 보류, 웨이퍼를 더 모으거나(검정력 계산으로 몇 장 필요한지 제시) split-lot 실험을 권한다. "유의하지 않음"을 "차이 없음"으로 쓰지 않는 대표 예다.

**③ 적층 수율**: 다이 수율 98%, 12단, 접합 수율 97% → 0.785 × 0.97 ≈ 76%.

## 10. 데이터 표 예시 (컬럼 감 잡기)

| 표 | 주요 컬럼 |
| --- | --- |
| 테스트 결과 (칩 단위) | lot_id, wafer_id, die_x, die_y, hard_bin, soft_bin, test_time, 측정값들 |
| 공정 이력 (lot·웨이퍼 × 단계) | lot_id, wafer_id, step, eqp_id, chamber_id, recipe_id, track_in, track_out |
| 계측 | lot_id, wafer_id, step, site(측정 지점), 항목(CD, 두께, 오버레이), 값, spec_low, spec_high |
